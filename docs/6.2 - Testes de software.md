# Testes de Software

## Instruções

Nesta etapa, foram realizados testes preliminares considerados fundamentais para o projeto do sistema de software que realiza a detecção do microssono. O primeiro passo realizado foi o de configuração dos dispositivos envolvidos no processo de teste, sendo eles, a Raspberry Pi 3 modelo B e o notebook de uso pessoal. A comunicação entre esses dispositivos ocorreu via SSH(Secure Shell), o qual foi primeiramente habilitado na Rpi3, seguido da conexão desse mesmo dispositivo a uma rede compartilhada por outro dispositivo, por meio da linha de comando _ssh pi@172.20.10.3_ . Uma vez que a conexão foi estabelecida, foi possível acessar o terminal da Rpi3, a partir do qual foi criado um diretório dedicado ao armazenamento dos arquivos de projeto da presente dupla.

Uma vez que o repositório foi criado, a Smartcam S600 foi diretamente conectada à porta de entrada USB-A da Rpi3 e um script em Python que implementa o método de Viola-Jones baseado em classificadores em cascata Haard foi projetado. A partir da biblioteca open source OpenCV, a qual possui um conjunto de classes dedicadas a aplicações de visão computacional. O script foi desenvolvido tomando como base o projeto conceitual de software previamente desenvolvido, carregando a rede nativa e leve de OpenCV responsável pela detecção de rostos e olhos. Em sequência, o script inicia a captura de vídeo, instante a partir do qual a Rpi extrai frames, reinicializa o contador e temporizador.

Após esses passos, uma conversão para a escala cinza foi realizada em conformidade com o projeto conceitual, visando filtrar a informação de crominância atrelada à cor das imagens, o que reduz a dimensão da matriz de tridimensional para bidimensional, evitando que a sobrecarga da memória RAM. No contexto presente projeto, essa técnica de processamento não impacta o desempenho da solução, visto que a cor da pele não impacta no processo de classificação, enquanto o contraste por outro lado, é o parâmetro de interesse. Posteriormente, uma chamada do método detectMultiscale() se encarregou de detectar o rosto exibido na câmera. Em seguida, um loop foi realizado para recortar apenas a região do rosto (region of interst) e procurar os olhos apenas dentro do pedaço do rosto.
